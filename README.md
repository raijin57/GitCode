# LeetCode File Organizer

Автоматический инструмент для организации файлов решений LeetCode задач. Скрипт автоматически создает структуру папок, перемещает `.cpp` файлы и получает условия задач с LeetCode и algo.monster.

## 🚀 Возможности

- **Автоматическая организация**: Создает папки для каждой задачи и перемещает `.cpp` файлы
- **Получение условий**: Автоматически получает условия задач с LeetCode (для обычных задач) и algo.monster (для Premium задач)
- **Обработка Premium задач**: Специальная обработка Locked задач с получением условий с algo.monster
- **Гибкая обработка**: Поддерживает различные форматы имен файлов, включая файлы с "Locked" в названии
- **Массовая обработка**: Может обработать все существующие файлы за один запуск

## 📋 Требования

- Python 3.7+
- Доступ к интернету (для получения данных с LeetCode и algo.monster)

## 📦 Установка

1. Клонируйте репозиторий или скачайте файлы проекта

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## 🔧 Настройка

Перед использованием укажите путь к папке с вашими `.cpp` файлами в скрипте:

```python
LEETCODE_PROBLEMS_PATH = "/path/to/CLionProjects/LeetCodeProblems"
```

## 💻 Использование

Запустите скрипт:

```bash
python leetcode_organizer.py
```

Скрипт выполнит следующие действия:

1. **Сканирование**: Найдет все `.cpp` файлы в указанной папке
2. **Извлечение номера**: Определит номер задачи из имени файла (например, `123.cpp` → `123`, `161Locked.cpp` → `161`)
3. **Создание структуры**: Создаст папку с номером задачи (если не существует)
4. **Перемещение файла**: Переместит `.cpp` файл в соответствующую папку
5. **Получение условия**: 
   - Для обычных задач: получит условие с `leetcode.com/problems/{slug}/description/`
   - Для Premium (Locked) задач: получит условие с `algo.monster`
6. **Создание документации**: Создаст `.md` файл с условием задачи в той же папке

## 📁 Структура результата

После обработки структура будет выглядеть так:

```
CLionProjects/LeetCodeProblems/
├── 1/
│   ├── 1.cpp
│   └── 1.md
├── 161/
│   ├── 161Locked.cpp
│   └── 161.md
├── 206/
│   ├── 206.cpp
│   └── 206.md
└── ...
```

## 🎯 Поддерживаемые форматы файлов

- `123.cpp` - обычная задача
- `161Locked.cpp` - Premium задача (будет обработана как задача №161)
- Любые другие форматы с номером в начале имени файла

## 🔍 Как это работает

1. **Извлечение номера задачи**: Используется регулярное выражение для извлечения номера из начала имени файла
2. **Получение slug**: Для получения названия задачи (slug) используется GraphQL API LeetCode
3. **Веб-скрапинг**: Условия задач получаются через парсинг HTML страниц
4. **Обработка ошибок**: При недоступности источника создается шаблон `.md` файла с ссылкой на задачу

## ⚙️ Конфигурация

Вы можете настроить поведение скрипта, изменив следующие параметры:

- `LEETCODE_PROBLEMS_PATH` - путь к папке с `.cpp` файлами
- Задержки между запросами (для избежания rate limiting)
- Формат выходных `.md` файлов

## 🐛 Обработка ошибок

- Если задача не найдена на LeetCode - создается `.md` файл с сообщением об ошибке
- Если algo.monster недоступен для Premium задач - создается шаблон с ссылкой
- Все операции логируются для отладки

## 📝 Формат .md файлов

### Для обычных задач:
- Заголовок с номером и названием задачи
- Ссылка на LeetCode
- Полное условие задачи
- Примеры входных/выходных данных
- Ограничения

### Для Premium (Locked) задач:
- Заголовок с пометкой "Premium Problem"
- Условие с algo.monster (если получено)
- Ссылка на algo.monster
- Шаблон для ручного заполнения (если получение не удалось)
